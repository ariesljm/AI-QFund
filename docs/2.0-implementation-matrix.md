## 已知缺口（按优先级）

1. **结算/质量闭环未运转**（settlement_ledger=0、quality_metrics=0）：推荐→监控→结算→质量→知识 的链路在真实数据上从未完整跑通，导致模块四全部停留在「影子」。这是「名存实亡」的第一根因。
2. **经理历史数据缺失**：无历史任职表，审计切片无法检测「经理变更」，只能看现任。
3. **推荐样本量 15 条**：校准层/影子闸门/重叠分组检验都需要更多截面，短期无法加速（除非接外部历史回填）。
