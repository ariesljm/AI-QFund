# 进化分层与权限（Evolution Layering）

架构决策：系统进化拆为**知识层 / 校准层 / 模型层 / 参数层**四层，权限逐层收窄——参数层冻结、否决类规则单向增严、信号类规则可退役。

## 四层权限

| 层 | 内容 | 变更权限 |
|---|---|---|
| **知识层** | Bad/Good-Case 知识库（复盘归因 → Few-Shot 回流，票 17） | **只增不改**；否决类（排雷规则）单向增严，非经重标定不得放宽 |
| **校准层** | 过程标尺（预测准确率/校准度）与 C 层参数 | 由知识库案例触发、有显著性证据才可调；护栏类阈值允许"更严"方向自动切换，**放宽需人工** |
| **模型层** | 特征集 + Booster（特征 schema 版本守卫 `feature_schema_version`） | 影子闸门（票 19）用证据定去留；特征增删必须递增 schema 版本 |
| **参数层** | λ 风险厌恶等一次性标定参数 | **冻结**；变更须全量重标定 + 人工批准 |

## Considered Options

- **单层全自动演化（1.x 的 GA/进化）** — 被拒：1.x `evolution_insights` 只有 2 行案例却挂着一整条自动演化机制，消费者已作废；无护栏的自动演化在样本量不足时把噪声学成规则。
- **全部人工** — 被拒：失去了"越来越好"的单调增长载体。

## Consequences

- 否决类规则（排雷、不可逆的 EXIT）与信号类规则（可退役的因子）在数据模型上分轨——不能混在同一张"规则表"里被同一机制增删。
- UI（票 23）须反映"这条规则是谁、凭什么加进来的"（历史可追溯）。
- 与 1.x 的最大分歧：**参数层冻结**意味着不再有运行期自动调参的自洽循环（如 GA 每期变异）。

## 冲突标注

与 ADR-0007（scipy 豁免）的关系：本 ADR 的校准层需要显著性检验（scipy 归属见修订后的 0007）；与 ADR-0008（标尺冻结）同构——冻结的都是"学出来的结论"，而非"喂进去的数据"。
