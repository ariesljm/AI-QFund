# 120 日主标尺扣费稳健性审计报告

- 日期：2026-09-17
- 工单：`.scratch/quant-hardening/issues/01-backtest-robustness.md`（票 01）
- 脚本：`scripts/backtest_robustness.py`
- 目的：回答"现状 3 因子排序（sharpe_60d + mom_250d + ttr_60d 反向，等权百分位）
  在扣费后的样本外是否仍有稳定预测力"——票 01 的 Q-STOP 判定材料

## 一、问题：原 120d 报告结论是否在独立重算 + 扣费下成立

`docs/backtest/120d-multifactor-rebuild.md` 的核心结论：简单 3 因子等权排序截面 IC +0.214、
高−低组收益差 +9.08%、t=3.17，"完胜" 15 维 LGBM；其中 sharpe_60d 单因子 IC +0.133。

本审计独立重算该结论，叠加三处原报告未做的处理：**扣申赎成本、purged 时间切分、
bootstrap 显著性、多因子 BH-FDR 校正**。

## 二、方法（单一来源，不重写公式）

| 环节 | 来源 | 说明 |
|---|---|---|
| PIT 因子 | `app.features.calculator.compute_fund_features` | 生产同款；dummy 指数只影响 capture_up/down/style_r2，不影响打分三因子 |
| 打分 | `app.engine.screen_pipeline.multifactor_scores` | 生产同款等权百分位 |
| 前瞻收益 | `app.repo.nav.forward_return_from_navs` | 生产同款，T→T+120 满窗口净值 |
| 扣费 | `net_fwd = fwd − 0.0065` | 120d 实际费率（赎 0.5% + 申 0.15% 前端） |
| 截面 IC | `app.features.stats.spearman` | 逐日因子（或组合分）与 net_fwd 的 Spearman 秩相关 |
| 显著性 | t 统计量 + bootstrap 95% CI（按决策日重采样 2000 次） | IC 序列均值是否异于 0 |
| 多重检验 | Benjamini-Hochberg FDR | 校正 8 因子扫描的选择偏差 |

**样本**：主动权益池（混合型 + 股票型，剔指数型）抽样 3000 只；2023-06-01 ~ 2026-04-01、
步长 12 交易日（≈月频）、57 个决策日、131488 条 fund×date 样本。
两次独立抽样（1500 / 3000）结论一致，本报告取 3000 只结果。

## 五、Q-STOP 判定：**部分触发**

Q-STOP 的触发条件是"扣费后 OOS IC 不显著 → 停下游"。本审计结果是**部分触发**，需拆开看：

1. **组合分（生产用 3 因子等权）扣费后全样本 IC 不显著**（p=0.156，CI 含 0）→ 生产打分的当前
   形态**不达标**。这符合 Q-STOP 的"现状不稳健"判断。

2. **但选基本身有 alpha**：mom_250d 在 BH-FDR 下显著存活（p=0.005），方向与原报告一致、量级接近。
   问题不在"基金选基有无 alpha"，而在**权重分配**。

3. **根因**：等权把三件事混在一起——
   - mom_250d（p=0.005，强信号，占 1/3）
   - sharpe_60d（p=0.94，纯噪声，占 1/3）
   - ttr_60d（p=0.94，纯噪声，占 1/3）
   
   **等权把唯一有效因子的强信号稀释成组合分的不显著**。这不是"因子无 alpha"，
   是"等权权重在主动破坏有效信号"。

### 对下游工单的影响

| 工单 | 原计划 | Q-STOP 后 |
|---|---|---|
| 03 因子权重（滚动 IC 加权 + 正交化 + regime 分层） | 地基通过后做 | **优先级提升、立即做**。等权已被证伪，不调权重组合分不可能显著 |
| 04 量化风险减项 | 地基通过后做 | **仍受 gate**：vol_20d 本审计未显著（p=0.25），风险因子预测力未验证，不可贸然进打分 |
| 02 组合层（贪心去相关） | 可并行 | **继续**：与因子权重正交，且组合分不显著时分散比选股更重要 |

## 六、局限（必须标注）

1. **survivorship 偏差**：fund_basic 是当前在世基金，已清盘/退市基金不在库 → 截面收益系统性
   偏高，IC 可能虚高。本结论的"不显著"在剔除幸存者后只会更弱，不会更强。
2. **伪 OOS 非干净 OOS**：原 120d 报告的因子选择已看过全样本，故"后段日期"只是时间稳健性
   而非真 OOS。后段显著（p=0.059）不能当作独立验证。
3. **绝对收益口径而非同类超额**：本审计用 net 120d 绝对收益做 IC，未用主标尺的"同类 RBSA
   中性化超额"（历史 RBSA 不可得）。绝对收益混入市场 beta，但 mom_250d 存活说明动量信号在
   绝对口径也成立——转超额口径后是否仍存活待验（ticket 03）。
4. **持仓类因子未纳入**：集中度/行业集中度（原报告结论为无信号）需 fund_holdings，本审计未算。
   对 BH-FDR 的因子数 m 偏小（8），FDR 校正偏宽松；但 mom_250d 的 p=0.005 足够小，结论稳健。
5. **样本期**：2023-06 ~ 2026-04 含单边下跌段（2024 初微盘股崩、2024H2 反弹），与原报告
   "验证期单边下跌"不完全同口径；两次独立抽样（1500/3000）结论一致，量级稳定。
