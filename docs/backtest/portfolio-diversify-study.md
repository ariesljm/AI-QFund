# 组合层验证：分散 Top5 vs 纯分数 Top5

- 日期：2026-09-17
- 工单：`.scratch/quant-hardening/issues/02-portfolio-construction.md`（票 02）
- 脚本：`scripts/portfolio_diversify_study.py`
- 目的：验证贪心去相关 + 同类≤2 是否在不牺牲收益的前提下降低组合风险

## 方法

每决策日：全市场算分（`nav_score_factors` + 生产 `multifactor_scores`，现 mom0.7/sharpe0.3）
→ Top30 候选 → 两条路：
- **纯分数 Top5**：按分取前 5。
- **分散 Top5**：`select_diversified`（相关性 60 日净值收益、同类 RBSA 第一行业 ≤2、
  max_corr=0.85、回退补满）。

扣费 0.65%，前瞻 120d，2023-06~2026-04、1500 只主动权益、57 决策日。

## 结果

| 组合 | 均收益 | 收益标准差 | 夏普代理 |
|---|---:|---:|---:|
| 纯分数 Top5 | +0.0483 | 0.1827 | 0.264 |
| 分散 Top5 | +0.0509 | **0.1591** | **0.320** |

- 分散相对纯分数：收益差 **+0.0026**（微升）、风险差 **−0.0236**（降 13%）、
  夏普代理 +21%。
- 两者重合度：均值 3.49/5、最小 1、最大 5——平均替换约 1.5 只，说明约束确实在
  换人而非全盘重排。

## 结论

分散约束**不牺牲收益、显著降风险**（夏普代理 +21%），符合组合层设计预期。
"5 只聚在同一风格峰值"的尾部风险被拆散。回退补满在样本期未触发（候选充足）。

## 局限

1. `rbsa_industry_1` 用 fund_features 最新快照（PIT 泄漏；RBSA 第一行业较稳定，
   影响小但需含历史 RBSA 的扩展回测复核）。
2. 收益标准差是组合日间收益的离散（风险代理），非真实持仓回撤。
3. 未模拟申赎费对换手的惩罚（分散引入的额外换手成本未扣；重合度 3.49/5 提示
   换手温和）。
