# 推荐系统量化改造：共识、成果与后续计划

> 文档记录 2026-08 grilling 审查达成的目标共识、阶段 0-6 改造成果，
> 以及受数据基座限制而延后的阶段 3/4 与止损重调的后续实施计划。

## 1. 目标共识（grilling 结论）

**系统主目标：在任何市场状态下，全天候搜索并推荐"未来 20 交易日绝对收益 > 1%"的基金（扣费后真赚钱），排序选最强，风险控制兜底长期正期望。**

| 维度 | 定义 |
|---|---|
| 主目标 | 期望绝对收益最大化（赚钱导向） |
| 赚钱定义 | 推荐后 20 交易日绝对收益 > 1%（覆盖申赎成本 + 缓冲） |
| 验收窗口 | 20 交易日统一（训练/排序/回测/度量）；EXIT 实际收益仅作 Web 展示 |
| 出手规则 | 全天候，无市场 gate；按模型预测收益 r̂ 横截面取 TopN；牛熊状态只作风险标注 |
| alpha 来源 | 信息优势：RBSA 持仓分析 + LLM 产业解读链路（"别人不能发现的机会"）；大路货动量因子降权 |
| 训练目标 | 未来 20 交易日**绝对收益回归**（R1），特征注入市场状态列让模型学 beta 分量 |
| 风险控制 | 监控防线兜底单笔亏损；回测验证止损参数（见 §5） |

## 2. 阶段成果（同口径 walk-forward 回测，2021-01~2026-08，67 决策日）

| 阶段 | 改动 | 赚钱胜率（决策日 r>1%） |
|---|---|---|
| 0 基线 | 现状系统（超额目标 + score>0 过滤 + 动量权重） | 37.3% |
| 1 R1 目标切换 | 训练目标改绝对收益 + 市场状态列（指数 20 日动量/波动率） | 38.8% |
| 2 过滤与排序 | 删 score>0 硬过滤（全天候 TopN）+ 权重模型主导（0.7/0.1/0.08/0.08） | **43.3%** |
| 5 度量与进化对齐 | 质量度量/GA fitness 切赚钱口径（+1.5~2.7pp 随阶段 1/2 累计计入） | — |
| 6 风控验证 | 2×ATR 追踪止损回测模拟 → **负贡献**（见 §5） | — |

辅助指标（阶段 0 → 阶段 2）：Top5 绝对收益均值 2.12% → 2.46%；排序 IC 0.148 → 0.180；最大回撤 -26.8% → -25.6%。

## 3. 数据基座扩展（阶段 3 前置工程，阻塞中）

**现状**：`fund_holdings` 每只基金只有最新一期持仓快照（2026-06-30），42 个报告期但每基金仅 1 期。

**为什么阻塞**：持仓变化率/行业漂移特征需要两期对比；且只有最新一期时，把它作为历史训练/回测样本特征 = 未来数据泄漏（用 2026 年持仓预测 2021 年收益），量化上不可接受。

**数据源支持**：东财 jjcc 接口的 `year/month` 参数当前留空（`app/data/foundation.py` `_async_fetch_holdings_one`），扩展为按年/季度遍历即可拉历史持仓。

**实施要点**：
1. 抓取范围：2020-01 ~ 当前（覆盖 walk-forward 回测起始 2021-01 前 12 个月）；12K 基金 × ~24 期 ≈ 数十万请求，需异步并发 + 限流重试 + 断点续传；
2. 存储：`fund_holdings` 保留多期（report_date 为复合键一部分），删除"仅存最新"逻辑；
3. 完成后回做阶段 3：`holding_turnover`（两期 Top10 替换率）、`rbsa_change`（第一行业权重变化）、`holding_top10_w`（集中度，单期即可算）；
4. 无前视注入：训练/回测样本日期 d 仅使用 `report_date <= d` 的最近一期。

## 4. 阶段 4 LLM 结构化信号（阻塞中）

**现状**：`macro_news` 仅 1 行历史（当日摘要），无法回测验证 LLM 信号增益。

**实施要点**：
1. `macro_agent.py`/`prompts.py`：LLM 输出结构化产业信号（赛道景气度评分、新闻事件→行业→基金传导的利好/利空映射）→ 存库 → 作为特征；
2. 赛道选择从"硬池一票否决"降级为约束标注；
3. 验证方式：历史数据不足，只能线上 A/B（带/不带 LLM 信号对比），周期长；
4. 前置依赖：数据基座先累积 macro_news 历史（每日管线自然累积）。

## 5. 止损重调（阶段 6 结论，2026-08 参数扫描完成）

**回测事实（67 决策日 walk-forward，单基金口径）**：

| 指标 | 固定持有 | 2×ATR 追踪止损 |
|---|---|---|
| 绝对收益均值 | +2.82% | -1.83% |
| 赚钱胜率（>1%） | 48.1% | 14.3% |
| 盈亏比 | 2.66 | 1.8 |

**参数扫描（fast 回测 730 天 13 期，Top5 组合口径）**：

| 配置 | 止损后收益 | 止损后赚钱胜率 | vs 固定持有 |
|---|---|---|---|
| 固定持有 | 5.99% | 75.0% | 基准 |
| 追踪止损 2×ATR | 2.33% | 50.0% | -3.7pp / -25pp |
| 追踪止损 4×ATR | 4.50% | 66.7% | -1.5pp / -8pp |
| 追踪止损 6×ATR | 5.78% | 75.0% | -0.2pp / 0 |
| 硬止损 -8% | 2.83% | 58.3% | -3.2pp / -17pp |
| 硬止损 -10% | 3.82% | 66.7% | -2.2pp / -8pp |

**结论：价格类止损在 20 日窗口 + 高胜率 Top 组合下结构性负贡献**（伤害随倍数放宽单调递减但无一跑赢固定持有）。
机制：Top 组合赚钱胜率 75%，亏损单仅 25% 且触发前已跌 2-8%（止损=确认亏损而非减少）；盈利单多数中途回撤 2-4% 被震出（踏空收益 > 止损省的亏损）。

**落地动作（已执行 / 待办）**：
1. 监控引擎追踪止损防线：价格触发从 EXIT 降级为警示（信息类离场仍保留 EXIT）；
2. 组合级风控替代：组合累计回撤阈值降仓（如 -8% 整体降仓）需后续回测验证；
3. 若保留价格类防线，仅作为极端保护（-20%+），且需更长持有窗口（30-60 日）重新验证。

## 7. 验收口径（统一）

- 训练/排序/回测/质量度量全部：**20 交易日绝对收益**；
- 赚钱阈值：**>1%**（覆盖申赎成本）；赚钱胜率 = 收益 >1% 的推荐占比；
- 对比基准：同参数 walk-forward 重训回测，对比上一阶段数字；
- GA fitness：赚钱胜率×2 + 期望绝对收益%（阈值 8.0 ≈ 4pp 胜率，匹配 fast 回测噪声）。
