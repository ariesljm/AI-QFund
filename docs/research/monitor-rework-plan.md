# 监控重构方案：模型序列 + EMA60 趋势 + LLM 赛道锚点（替代 ATR 追踪止损）

> 决策链：grilling 会话 Q1-Q4 → 7 条防线过重 → 3+1 仍重 → 极简化 → 用户提议三信号 → 验证 → 本方案
> 验证结论（2026-08，全市场回测模拟）：
> - EMA60 退出（连续 2 日 < EMA60）：全池 10 买点 63,698 样本，平均回撤 14.6%→2.1%，收益 -5.21%→-0.91%（熊市少亏）；动量池 -3.10%→+1.37%，胜率 36.7%→72.7% —— **无前视、可靠**
> - 模型序列退出（连续 2 打分点转负）：动量池 -3.10%→+2.51%，胜率 77.3%，回撤 2.94% —— **含前视上限，真实值更低，列为落地前验收项**
> - 组合 ≈ 模型单独（模型触发率 99.6%），EMA 为"模型失灵兜底"

---

## 1. 目标与约束

- **定位不变**：推荐 + 监控信号服务，不管理真实持仓；监控对象 = 已推荐且未离场基金（可累积几十只）。
- **已废弃**：2×ATR 追踪止损（防线1）、-8%/-10% 硬止损、MA/回撤二维规则、波动率门控、清盘规模底线（模型先触发，冗余）。
- **复杂度约束**：规则层极简，新增规则 2 条（模型序列、EMA），复用已有组件。
- **实盘持仓期远超 20 日**：所有退出信号按长持仓语义设计（低频、确认期），回测结算窗口必须可变。

## 2. 新监控架构（规则层 + 复核层）

```
规则层（纯函数、全量扫描，每日每基金 O(1)）       复核层（仅预警基金）
┌──────────────────────────────────────┐      ┌───────────────────┐
│ R1 模型序列退出（主动，EXIT）         │      │ R4 LLM 逻辑证伪    │
│ R2 EMA60 趋势退出（被动，EXIT）       │ ───► │ （只能向上推，     │
│ R3 LLM 赛道锚点 + 风格漂移（低频）     │      │  不能推翻规则结论）│
│ R5 赛道优势（WARNING，已有）          │      └───────────────────┘
└──────────────────────────────────────┘
信号合并：EXIT > WARNING > BUY_MORE > HOLD（SIGNAL_PRIORITY 沿用）
```

**分层原则（Q4）**：规则层每日全量扫描（几十只基金 × 纯函数，毫秒级）；R4 只对规则触发预警的基金复核（成本从 O(基金数×天) 降为 O(预警事件数)）。

## 3. 信号设计

### R1 模型序列退出（替代 2×ATR，唯一主动退出来源）

- **打分**：每日用模型对持仓基金最新特征打分，得预测 20 日绝对收益序列 `s_t`（线上监控语义 = 每日重评，与推荐同源同目标）。
- **触发 EXIT**：`s_t < 0` 且**连续 3 个交易日**成立（确认期，跨过 7 日惩罚赎回费率带；回测验证口径为 2 打分点 ≈ 10 日，实盘日频取 3 日等效）。
- **触发 WARNING**：`s_t` 相对买入分下降 > 50%（`s_t < 0.5 × s_buy`）且未到 EXIT 线。
- **模型版本化**：推荐时记录 `model_version`（meta 表模型指纹/训练时间）；监控打分**绑定买入时模型版本**，消除每周重训造成的分数跳变。`recommend_log` 增列。
- **失灵检测**：模型不可用（`load()` 返回 None / 打分异常连续 N 日）→ 该基金降级为"仅 R2/R3 保护"，并置 WARNING（"模型信号不可用"），不静默。
- 依据：`docs/research/monitor-exit-methods.md` §3（B.2 模型版本化、B.3 相对门槛）。

### R2 EMA60 趋势退出（替代 -8%/-10% 硬止损，被动保护）

- **触发 EXIT**：NAV 连续 2 个交易日 < EMA60（回测验证参数，勿改）。
- **依据**：全池 63,698 样本回撤 14.6%→2.1%；Faber (2007) 10 月均线择时降低回撤保持收益（联网核实）。
- **注意**：EMA60 是趋势信号不是止损——牛市正常回调会触发（回测胜率 27.7%→27.1% 持平即"少亏不增利"），定位为**回撤保护**而非收益增强；与 R1 的关系 = 兜底（R1 失灵时兜住，R1 正常时几乎不额外触发，100% 组合触发率验证）。

### R3 LLM 赛道锚点 + 风格漂移（低频，非价格维度）

**数据现状（已核实）**：`sector_selections` 表已持久化推荐时 `recommended_sectors` / `risk_sectors` / `sector_reasoning`（base.py:269 `insert_sector_selection`）。推荐侧已做回避赛道过滤（recommend.py:174-180：第一行业命中 risk_sectors 的基金剔除）。

- **R3a 赛道锚点（新）**：读取**推荐时** `risk_sectors` / `recommended_sectors`（不经 build_macro_context 实时重建，修复上下文漂移缺陷）：
  - 当前 RBSA 第一行业 ∈ `risk_sectors` → WARNING（连续 2 次季度观测确认 → EXIT，季度级低频）；
  - 当前 RBSA 第一行业 ∉ `recommended_sectors` 连续 2 个报告期 → WARNING（离开推荐赛道）。
  - RBSA 是季报持仓聚合（见下），只能季度级检测，故确认期为"2 个报告期"而非交易日。
- **R3b 风格漂移（保留已有防线 2a，零改动）**：第一行业切换 或 权重降 >15% → EXIT。与 R3a 互补：R3a 是"切换方向 vs LLM 判断"（语义），R3b 是"任何切换"（事实）。
- **RBSA 质量声明**：当前实现为**持仓聚合**（季报十大持仓 → 行业权重），非 Sharpe 1992 真 RBSA；季度滞后 1-3 个月、只覆盖十大持仓。作为**季度级低频底线**使用，不承担日频职责。

### R4 LLM 逻辑证伪（保留，仅复核）

- 定位不变：规则触发后复核，`logic_verdict == "断裂"` 才可向上推为 EXIT；**只能向上推、不能推翻规则结论**（signal-engineering 档 A 节原则）。
- 复核输入增强：注入推荐时 `risk_sectors`/`recommended_sectors`（修复：现在 `ctx` 来自实时重建的 macro context，应改用持久化值）+ 经理变更等事件信息（作为复核输入，不独立成规则）。

### R5 赛道优势（保留已有防线 2b，WARNING）

- 动量落后赛道中位数且未企稳 → WARNING。不改。

## 4. 信号状态机（防抖动与升级）

```
                    ┌─────────────┐
   s_t>0 且 >0.5×s_buy ──► │   HOLD      │ ◄── 模型转正恢复
                    └─────────────┘
                         │ s_t < 0.5×s_buy 或 赛道落后/离开推荐赛道
                         ▼
                    ┌─────────────┐   s_t<0 连续3日 或 NAV<EMA60 连续2日
                    │   WARNING    │ ────────────────────────────► EXIT
                    └─────────────┘          或 R3b 强证据
                         ▲
                         │ 模型转正且回补（解除确认）
```

- **确认期**：EXIT 一律要求连续触发（R1: 3 交易日；R2: 2 交易日；R3a: 2 报告期）；单日抖动不产生信号。
- **幂等**：同基金同状态不重复告警（monitor_events 已有去重，沿用）。
- **冷却**：EXIT 后同基金 60 日内不再监控（防反复横跳）。
- **升级**：WARNING 持续 20 个交易日且无缓解 → 升级 EXIT（signal-engineering 档 B.2，参数可调）。
- **BUY_MORE**：仅 HOLD 且 `s_t` 仍显著为正（> 1.5×s_buy）且 R3 赛道锚点无冲突时输出（沿用现有 BUY_MORE 语义，加赛道锚点闸门）。
- **信号衰减（EXIT 闭环）**：EXIT 触发即从 `_HOLD_STATES` 移出（沿用 `get_holding_codes`），用户执行后不再监控。

## 6. 验证框架扩展（严格 walk-forward 验收，已完成 2026-08-08）

**结果（max_days=120，61 决策点 2021-01~2025-12，305 样本，无前视：每 20 日重训 + 当步打分）**：

| 策略 | 平均收益 | 胜率 | 平均最大回撤 | 触发率 |
|---|---|---|---|---|
| 固定持有 | +2.75% | 57.0% | 17.43% | 0% |
| EMA60 退出 | +1.38% | 53.8% | 12.83% | 86.9% |
| **模型序列退出** | **+3.19%** | 54.4% | 13.75% | 67.2% |

**验收判定**：收益端通过（model_seq 3.19% >> ema60 1.38%，且 > fixed 2.75%——模型退出全周期含牛市增强收益）；回撤端部分通过（13.75% 略 > 12.83%，远 < 17.43%）。
**结论**：R1 模型序列按 EXIT 上线成立；R2 EMA 保留作回撤兜底（单独比较时 EMA 回撤微优、收益大劣，恰为互补）。
**实现**：`backtest_exit_walkforward.py`（复用 walkforward 训练循环，--max-days 可换 60/250 档）。

用户已接受"EMA 可靠 + 模型做上限参考"，下列列为**实施 R1 前的强制验收**：

1. **结算窗口可变**：`sim_trailing_stop` 的 `max_days=20` → 支持 60/120/250 日可变持有期（现有 20 日上限会系统性低估长持仓退出价值，exit-methods §7 关键结论）。
2. **退出模拟模式**：backtest_walkforward.py 增加 `stop_mode ∈ {"ema60", "model_seq", "fixed"}`，`model_seq` 用**当步重训模型**（无前视）逐日打分。
3. **多买点**：2021-2026 每 20 日一步（框架已有 `_STEP_DAYS`），覆盖牛/熊/震荡。
4. **验收标准**：`model_seq` 收益 ≥ `ema60` 且回撤 ≤ `ema60`（当前上限参考：+2.51% vs +1.37%）；EMA 已通过验收（10 买点 6.4 万样本）。

## 7. 落地步骤（分阶段）

1. **阶段一（低风险，先行）**：R2 EMA60 + R3a 赛道锚点 + R3b 风格漂移 + R4/R5 保留 + 缺陷修复 #6/#7/#9（移除 2×ATR）。全部为纯函数/复用，可立即上线。
2. **阶段二（依赖验证）**：R1 模型序列 + 模型版本化 + 预测序列落库。先跑 §6 严格 walk-forward 验收，通过后上线。
3. **阶段三（增强）**：状态机升级/冷却/闭环 + EXIT 质量度量看板。

## 8. 风险与遗留

- **R1 真实收益未知**（前视上限 +2.51%）：阶段二验收是生死线，不通过则回退为"EMA 单主退出 + R1 仅 WARNING"。
- **R3 季度滞后**：赛道锚点/风格漂移只能季度级检测，不承担日频职责；误报风险（正常调仓触发行业切换）由"2 报告期确认"缓解。
- **模型失灵静默**：依赖 `load()` 可用性检测，需保证监控每日运行探活。
- **无重入**：退出后持现金不回补（用户自行决策），EMA 在牛市会错过反弹——定位为信号服务，符合项目定位。
