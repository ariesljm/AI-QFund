# 智能基金推荐与动态转向监控系统技术规范文档

## 1. 系统概述与总体架构

### 1.1 系统定位与核心目标

本系统是一个由量化统计模型（LightGBM）**与**大语言模型（LLM）协同驱动的非对称架构基金推荐与监控平台。系统不干预用户建仓决策，专注于达成三大业务目标：

1. **提供最佳基金推荐**：通过全市场量化初筛结合 LLM 深度定性排雷，杜绝追高，选出具有独立 Alpha、估值安全边际高且质地优良的标的。
2. **动态转向监控与及时预警**：在基金持仓周期内，高频跟踪底层走势脱轨与动量衰竭信号，在拐点来临前发出退出警报。
3. **闭环持续自我进化**：建立样本外定期复盘、特征有效性衰减治理与 LLM 排雷规则库动态扩充机制，抵抗市场非平稳性与概念漂移。

## 2. 模块一：全市场量化初筛引擎 (LightGBM Engine)

### 2.1 交易可行性硬过滤 (Hard Pre-filtering)

在进入特征计算前，通过规则引擎剔除不可交易或容易产生误导的标的：

* **限购过滤**：剔除单日申购上限 $< 1000$ 元或暂停申购的基金。
* **规模底线**：合并规模（AUM）$< 5000$ 万元（清盘风险）或单一产品规模 $> 100$ 亿元（策略容量钝化）。
* **存续期约束**：基金经理任职当前产品时长 $< 6$ 个月者剔除。

### 2.2 防追高 Label 设计

为了避免模型拟合短期高动量导致的“追高接盘”，训练目标强制绑定下行回撤惩罚，采用**风险调整后超额收益**：

$$Label_{i, t} = \left( R_{i, [t, t+60]} - R_{benchmark, [t, t+60]} \right) - \lambda \cdot \text{MaxDrawdown}_{i, [t, t+60]}$$

* $R_{i, [t, t+60]}$：未来 60 个交易日的绝对收益率。
* $R_{benchmark, [t, t+60]}$：该基金对应同类基准的平均收益率（同类中性化）。
* $\text{MaxDrawdown}$：未来 60 个交易日内的最大动态回撤。
* $\lambda$：回撤惩罚系数，生产环境设定为 $1.5 \sim 2.0$。

### 2.3 核心特征工程

| 特征维度 | 特征名称 | 计算公式 / 逻辑 | 业务目的 |
| --- | --- | --- | --- |
| **反追高与过热** | 动量加速度 ($\Delta Mom$) | $\frac{R_{1m}}{R_{6m} / 6}$ | 识别短期内涨幅透支中长期的过热标的 |
|  | 均线乖离率 ($Bias_{60}$) | $\frac{NAV - MA_{60}}{MA_{60}}$ | 衡量价格是否处于极端超买区间 |
|  | 份额激增度 ($AUM_{surge}$) | $\frac{Shares_t - Shares_{t-1}}{Shares_{t-1}}$ | 规避基民盲目涌入导致建仓变形的产品 |
| **底层性价比** | 重仓股加权 PE 分位 | $\sum w_i \cdot \text{PE\_Percentile}_{3y}(Stock_i)$ | 确保底层资产处于历史估值合理或偏低水平 |
|  | 持仓 PEG 匹配度 | $\frac{\text{Weighted\_PE}}{\text{Weighted\_Growth}}$ | 挖掘高盈利增速与低估值匹配的黑马 |
| **收益质量** | 上下行捕获比率 | $\frac{UpCapture_{1y}}{DownCapture_{1y}}$ | 挑选上涨能跟住、下跌抗跌性强的主动管理能力 |
|  | 回撤修复周期 | 最近一次最大回撤触底到创历史新高天数 | 评估基金经理纠错与调仓胜率 |

### 2.4 回测防作弊与交叉验证

* **Point-in-Time 机制**：持仓报告数据严格以实际公告发布日（Disclosure Date）作为可见截面，杜绝利用未公开季报持仓的未来函数。
* **隔离滚动划分（Purged Time-Series Split）**：按季度推进滚动训练窗口（如训练期 2 年，验证期 1 季度），在训练集与测试集之间预留 60 个交易日的 Purge Gap。

## 3. 模块二：LLM 定性审计与排雷引擎 (LLM Due Diligence)

经过 LightGBM 筛选出预测分最高的 Top 30 候选池后，调用 LLM 充当“风控委员会”，行使定性一票否决权。

### 3.1 检索与数据装配管线 (Context Assembler)

自动化脚本抓取并聚合以下四组非结构化/半结构化切片，填充入 Prompt：

1. **持仓异动切片**：近两期重仓股留存率、新进重仓行业属性、集中度变化。
2. **重仓股风险雷达**：Top 10 重仓股近 30 天负面公告（立案调查、质押暴雷、业绩预亏、减持潮）。
3. **管理团队变动**：基金经理增聘（老带新共管多为离职前兆）、在管总规模过快攀升。
4. **舆情与舆论争议**：主流投资社区中关于基金风格漂移、大幅高位接盘题材的集中争议。

### 3.2 审计 Prompt 模板与 JSON Schema 约束

### 3.3 复合推荐分计算

* 若 `audit_verdict == "VETO"` 或 `risk_score > 60`，直接剪枝剔除。
* 对留存基金计算综合最终得分：
$$Final\_Score = Score_{LightGBM} \times \left( 1 - \frac{Risk\_Score_{LLM}}{100} \right)$$


* 选取综合得分最高的 Top 5 基金输出给用户。

## 4. 模块三：动态转向与退出监控引擎 (Turnaround Monitor)

系统每日收盘后对推荐中处于上涨趋势的基金执行批处理检测，通过高频信号捕捉反转拐点。

### 4.1 隐形调仓与脱轨检测 (Proxy Portfolio Tracking)

利用上一期季报前十大重仓股构建归一化虚拟持仓，每日滚动监测实际净值与虚拟持仓的拟合偏离度。

```python
import numpy as np
import pandas as pd

def check_portfolio_drift(
    fund_daily_ret: pd.Series, 
    proxy_daily_ret: pd.Series, 
    window: int = 15
) -> dict:
    """
    计算滚动相关系数与 R^2，识别隐形风格漂移或调仓
    """
    rolling_corr = fund_daily_ret.rolling(window).corr(proxy_daily_ret).iloc[-1]
    
    # 简易无截距回归计算拟合度 R^2
    x = proxy_daily_ret.tail(window).values
    y = fund_daily_ret.tail(window).values
    if np.std(x) == 0 or np.std(y) == 0:
        r2 = 0.0
    else:
        r2 = max(0.0, np.corrcoef(x, y)[0, 1] ** 2)
        
    is_drifted = (rolling_corr < 0.40) or (r2 < 0.25)
    
    return {
        "rolling_corr": round(rolling_corr, 4),
        "rolling_r2": round(r2, 4),
        "is_drifted": bool(is_drifted)
    }

```

### 4.2 动量衰竭与估值透支信号体系

* **超买背离信号**：净值创出 60 日新高，但日度成交/换手波动放大，且近 5 日相对同类基准的超额收益（Alpha）连续为负。
* **估值天花板信号**：前十大重仓股加权 PE 处于过去 3 年历史分位数的 $\ge 90\%$ 区间，安全边际耗尽。
* **均线破位**：净值下穿 20 日指数移动平均线（EMA 20）。

### 4.3 动态预警三级状态机

```
               ┌──────────────┐
               │  状态：HOLD  │
               └──────┬───────┘
                      │ 触发任一预警指标：
                      │ - 隐形调仓脱轨 (Corr < 0.4)
                      │ - 估值分位 > 85%
                      │ - Alpha 连续 5 日为负
                      ▼
               ┌──────────────┐
               │ 状态：WATCH  │ <────┐ (指标修复，解除预警)
               └──────┬───────┘      │
                      │              │
        满足以下任一组合条件：         │
        1. 处于 WATCH 且跌破 EMA20   │
        2. 估值 > 90% 且动量大幅翻负  │
        3. LLM 检出重仓股致命负面公告 │
                      ▼              │
               ┌──────────────┐      │
               │  状态：EXIT  │ ─────┘
               └──────────────┘
               (推送平仓/止盈信号)

```

| 状态 | 触发阈值条件 | 系统动作 |
| --- | --- | --- |
| **HOLD (正常持有)** | 拟合度 $Corr \ge 0.7$；重仓估值分位 $< 80\%$；均线多头排列 | 维持推荐状态，常规数据监控 |
| **WATCH (重点观察)** | $Corr < 0.4$ 或 $R^2 < 0.25$；或重仓估值分位 $\ge 85\%$；或 Alpha 连续 5 天衰减 | 移出新用户推荐流；向已持有用户展示“预警状态”，提示进入高波区间 |
| **EXIT (止盈/避险)** | WATCH 状态下净值跌破 EMA 20；或估值超 90% 且 5 日动量由正转负；或触发突发黑天鹅公告 | 向用户推送即时“建议离场/锁定收益”告警，并在系统看板标记该推荐周期结束 |

## 5. 模块四：系统自我进化与闭环治理 (Self-Evolution)

为了防止模型长期运行后策略失效，系统通过“量化模型影子滚动更新”与“LLM 排雷规则库持续学习”实现闭环进化。

### 5.1 Champion-Challenger 滚动重训机制

1. **重训周期**：每季度末（公募基金季报披露完毕后 5 个工作日内）自动触发。
2. **影子运行（Shadow Mode）**：
* 现役模型（Champion Model）继续负责线上生产任务。
* 新训练出的候选模型（Challenger Model）在测试环境接入每日最新数据并行空跑 15 个交易日。


3. **自动切换指标**：
只有当 Challenger 在样本外的**信息比率（IR）高于 Champion 15%** 且**最大回撤低于 Champion** 时，系统才触发模型自动热更新；否则保留 Champion 并触发参数告警。

### 5.2 复盘归因与 LLM 知识库自动进化

系统设立自动化“事后复盘（Post-Mortem）”任务，监控退出信号发出后的样本表现：

```
[推荐后产生异常回撤 (> 8%) 或触发出场]
                   │
                   ▼
       [自动化归因诊断 Agent]
      /                      \
    量化特征滞后?           非结构化隐患漏判?
    /                          \
[记录特征权重失效]          [生成标准 Bad-Case]
       │                               │
       ▼                               ▼
[纳入季度重训特征剔除库]    [持久化写入 LLM RAG / Few-Shot 知识库]
                            (例如补充："注意高管频繁变更但未达公告标准的个股")

```

### 5.3 进化防退化安全红线

* **禁止在线黑盒调权**：禁止根据日度收益率对 LightGBM 进行在线强化学习或实时改权，防止追逐短周期市场噪音。
* **规则单向增严**：LLM 排雷规则库在自主沉淀过程中，只允许新增“排雷否决场景”，严禁模型自动放宽“一票否决”标准。
* **人工熔断干预**：系统提供全局安全降级开关。当全市场出现极端系统性流动性危机时，系统可一键降级至“仅依赖低波防御因子”的基础规则集。
